# SolPrende en 3D

Pitch en 3D de SolPrende (ICOM802, Grupo 3): Felipe Chartier, Natalia Gómez, Constanza Santander y Antonia Zúñiga.

El ahorro se enciende desde arriba.

Abre `index.html` desde GitHub Pages (Settings → Pages → rama `main`, carpeta raíz). Usa three.js desde jsDelivr; los modelos van en `modelos/*.glb.txt` (base64).
